# resume-screening
# AI Resume Screening using n8n + Google Gemini

## Overview

This project automates resume screening using n8n and Google Gemini AI.

## Workflow

Manual Trigger
↓
Resume & Job Description
↓
Gemini AI
↓
Score Generation
↓
Selected / Rejected
↓
Merge Results

## Technologies

- n8n
- Google Gemini
- JavaScript
- JSON

## How to Run

1. Import workflow.json into n8n.
2. Configure Google Gemini credentials.
3. Execute the workflow.
4. Review the Selected/Rejected candidates.
